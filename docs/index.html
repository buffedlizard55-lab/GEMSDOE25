Why B2 can work — and what it does not prove

Fresh pixel checks show B2 is exactly D2.8 with 6,436 predictions within 200 m of the supplied catalogue removed. GEMSDOE36 is B2 plus 1,200 predictions. GEMSDOE25 and 30 have identical masks; GEMSDOE28 R1 and 31 have identical masks.

DTI rewards the strongest nearby prediction for each truth pixel while charging false-positive mass. Thinning can preserve coverage while removing redundant predictions. Collar pruning may reduce low-value emissions. The hidden labels are unavailable, so this is a conditional explanation—not proof of the cause of the reported score.

Formula: S = T / (0.2(T + F) + 0.8N). Removing credit t and false-positive mass f helps only when t/f < 0.2S/(1−0.2S). No amount of filename novelty establishes that condition.

How a submission becomes eligible

  1. Research gate. Beat the same-run best comparable buffered holdout; report pooled HOLDOUT-DTI, evaluator version, withheld-positive count and 95% CI. Confirm on fresh draws.
  2. Novelty gate. Check the surface before placement and exact final dots against the registry. Stop for rank correlation above 0.90 or more than 70% within 3 px. Renaming, changing compression or filling outside NaNs is not a new prediction.
  3. File gate. One float32 GeoTIFF band, finite predictions in [0,1] throughout the template footprint, identical CRS, shape and geotransform. Use the shared writer; reject invalid data instead of silently clipping it.
  4. Selector gate. Separate authorization and a verified remaining weekly slot are required. The software must not infer either from a format-pass receipt.
  5. Only after all gates pass: download the exact approved hash-linked TIF, open the competition submission form, select that TIF (not this report or JSON), paste its ≤140-character note and save the organizer receipt. This project does not automate upload.
