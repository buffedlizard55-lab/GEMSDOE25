  2. Check absolute full-footprint rank correlation against every declared reference before dot placement and on the final file; stop for |ρ| > 0.90 or >70% of candidate dots within 3 pixels of any reference. Missing, misaligned or unavailable references are unverified, not a pass. Do not waive dense references.
  3. Independently re-read the exact TIFF and verify SHA-256, one float32 band, the pinned template's CRS/shape/transform, finite [0,1] values inside the footprint, and the exact known-fault mask.   4. Run python scripts/verify_candidate_independent.py path/to/candidate.tif. If proposing a ZIP, add --require-zip and verify that it contains exactly the audited TIFF bytes. A pass permits selector review only and does not authenticate the evidence or authorize a slot.
