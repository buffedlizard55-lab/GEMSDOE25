What this means for a submission

  • Best-known target to beat on these sites: GEMSDOE32 h33-h33-2-b2, owner-reported 0.2778 — itself a deterministic catalogue-collar deletion of H19-5, not new geological discovery. Every file scoring ≥ 0.2449 except GEMSDOE70 (0.2478) is a ≥ 96.9% pixel subset of H19-5.
  • Why collar deletion raises the score (inference from owner-reported claims): masking removes known-fault pixels that score nothing; hidden truth is depleted within ≈200 m of mapped traces, so deleting low-yield near-catalogue dots lowers weighted false positives faster than true positives. This is score geometry, not new-fault detection.

How to make a submission (DrivenData form)

  1. Download the selector-approved .tif (or ZIP containing exactly one GeoTIFF) and verify its SHA-256 against its receipt.
  2. Open the competition page, sign in, and use the upload control (single-band GeoTIFF or a .zip with one GeoTIFF).
  3. Confirm the file matches the submission format: same CRS (EPSG:32611), shape (3730 × 3292) and geotransform (100 m, origin 243350 / 4508550) as the training data; one float32 band; values in [0, 1]; data outside the bounds null/NaN.
  4. Enter the copy-ready note in the form's optional Note field (short comment, ≤ 140 chars recommended), e.g. GEMSDOE25 H-N1 | radiometric alteration-ratio edge x conductive-base edge; catalogue-free blind-faul | id 499f800100d0 | not yet live-scored.
  5. After an authorized upload and organizer receipt, record the result with python scripts/record_live_score.py --file <exact-file-or-content-id> --score <receipt-score>. Never enter a projection or proxy value as a score.
Common rejection cause seen on this project: "Predicted values must be in range [0, 1]" — caused by NaN pixels inside the template footprint on an earlier file (NaN fails every range test). H-N1 has zero NaN anywhere and zeros outside the footprint; verify before upload with python scripts/verify_candidate_independent.py docs/downloads/gems25-hn1-rad-base-edge-20261026-499f800100d0-zeros.tif.
