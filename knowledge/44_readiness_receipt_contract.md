# Selector-readiness receipt contract

`python scripts/check_readiness.py evidence.json --output decision.json` performs **consistency checks on supplied JSON only**. It neither calculates the underlying analyses nor authenticates an organizer receipt. `SELECTOR_REVIEW_ONLY` is not upload, slot, scientific, or organizer approval. Missing, malformed or incomplete evidence returns `DO_NOT_SUBMIT` and exit code 1. The [current no-candidate run card](../registry/run_card_b0b734ae_2026-10-28.json) intentionally does not provide these receipts and [fails this gate](../evidence/readiness_decision_b0b734ae.json).

## Required evidence object

All section objects below must contain the identical lowercase 64-hex `raster_sha256`. The root also needs that hash and a nonempty **assigned** `lane` string. Boolean keys must be true/false JSON booleans, not strings. Do not fabricate an evidence object from these descriptions: compute and preserve each underlying receipt first.

| Section | Required fields and meaning |
|---|---|
| `format` | `no_nan_inside`, `values_in_range`, `whole_array_finite_in_0_1`, `crs_match`, `shape_match`, `transform_match`, `single_band`, `dtype_float32`, `catalogue_mask_exact` all true; `template_sha256` and `labels_sha256` from the pinned inputs. Whole-array strictness is a conservative local policy, not an organizer-confirmed padding convention. |
| `surface` | `registry_complete` true, `max_abs_rank_correlation` ≤0.90, `registry_manifest_sha256`, `template_sha256`, `rank_footprint_pixels` 5167373, positive `registry_checked`, and `scores_sha256` of the exact pre-placement surface. The identity of the surface used to place final dots must be preserved independently. |
| `dots` | Same registry manifest, template, footprint count and reference count as `surface`; `surface_sha256` must equal the surface's `scores_sha256`. Require complete registry, `max_abs_rank_correlation` ≤0.90, `max_overlap_3px` ≤0.70 and `exact_duplicate` false. Never omit dense references or silently resample misaligned ones. |
| `holdout` | `evidence_class` = `HOLDOUT-DTI`; nonempty `evaluator_version` and `evaluator_sha256`; `labels_sha256` equal to the format receipt; `stage` = `confirmation`; `run_id`; positive integer `withheld_positives`; true `same_run_comparator`, `whole_segment_buffered`, `visible_only_features`, `visible_mask_exact`, `pooled`; `alpha` 0.2, `beta` 0.8, `kernel_m` 300, `kernel` `triangular`; `dti`, two-element `dti_ci95`, `comparator_dti`, and strictly positive two-element `paired_delta_ci95`. Candidate must exceed comparator. `cells` is a list of unique `{"fold": 0..3, "draw": nonnegative_integer}` objects, with the same two or more confirmation draws in each fold. |
| `canary` | Same `run_id` as holdout, `all_features_tested` true, unique nonempty `feature_names`, `max_auc` ≤0.90, and one `cells` record for each holdout fold/draw. Each record has `fold`, `draw`, and a `features` mapping with exactly the declared names; every feature has `passed: true` and finite `canary_auc` ≤0.90. The supplied maximum must equal the maximum of all individual records. |

The focused synthetic example in `tests/test_readiness.py::complete` illustrates structure only; its hashes and scores are deliberately fake test data and must never be submitted as an experiment receipt. A real assembler must bind actual output files from the shared surface and dot checkers, independent validator, canary and pooled holdout. In particular, the final-dot CLI does **not** establish by itself that its dots were made from a particular surface; an auditable construction record is required to provide the `surface_sha256` linkage. Current gate fields are assertions that must be independently verified against these source artifacts.

The locally restored registry is itself only a declared pinned subset. Even a successful comparison against that subset does not prove novelty against unlisted sibling submissions. The present registry also contains a mismatched transform and therefore cannot currently pass the literal full-registry audit without an authorized resolution.
