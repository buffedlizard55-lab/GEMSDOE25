## Frozen CF-1 design

1. Fill only missing band samples by existing nearest-fill routine. Gaussian derivative sigma=2 px on each field, normalize each gradient vector's magnitude by its **own** footprint 90th percentile; cross-field score = min(normalized RTP and gravity magnitudes, 3) × |cross(unit gradients)|, clipped to 3, float32. This is a static *catalogue-free* layer. Derivative kernel and quantile are fixed, not tuned.
2. On the *surface before placement*, check absolute Spearman versus all available registry TIFs, flag >0.90; if failed stop. Check each feature alone as a canary on the same held-out truth sample: absolute ROC AUC >0.90 means presumed leakage; stop. No catalogue-derived feature may see withheld components: `Cell` shared harness builds these from visible only.
3. Paired hide-and-recover: four spatial quadrants, draw seed 21 (one draw, low-power screen), full components withheld with buffer, BDE+7 same-run comparator `C`, CF-1-added `A`, HGB defaults shared, equal min-distance 2.4px / top 3.5% score-ordered ridge emission. Score pooled DTI via shared `Cell.evaluate` (alpha 0.2 beta 0.8 300m triangular kernel); exact pixel masking. Report 95% t interval across four fold differences; report withheld truth count and per-fold DTI; no organizer score.
4. Gate: positive mean ΔDTI >0.001, at least 3/4 positive folds, worst fold ≥−0.010, canary max |AUC−0.5| corresponding to AUC ≤0.90. A screen pass would need *independent* confirmation draw 22 before promotion. If screen fails, **negative**. No weekly slot used.
5. Any artifact built for the urgent download request after a failed gate is explicitly a **negative, DO NOT SUBMIT** diagnostic. Check *final* dots against all available registry rasters (including lattice), fail closed if >70% in 3 px of any one or |Spearman|>0.90. A format validator pass does not override that verdict.
