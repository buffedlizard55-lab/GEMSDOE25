## 3. Frozen Mathematical Specification of Top Candidate `H74-1` (`src/gems25/h74_rmps.py`)

All four columns in `H74_RMPS_NAMES` are strictly static, finite `float32` in `[0, 1]` on the `5,167,373`-pixel footprint, reading **zero** label/catalogue files (`labels.tif`, `existing_faults.tif`, `gdr_qfaults_traces.csv`, or `dist_known_fault_px` are never opened). Let $\operatorname{pct}(X)$ denote clipping $(X - p_1)/(p_{99} - p_1)$ to `[0, 1]` using percentiles computed on the `4 px`-eroded footprint interior (`foot_core`).

1. **`H74_remanent_skew_crest`:**
   * Fill nodata via `nearest_fill` on `14_tmi`, `02_rtp`, `09_tmi_vg`.
   * Smooth `tmi` and `rtp` with Gaussian $\sigma = 1.5\text{ px}$; compute unit-consistent horizontal gradients $G_{\text{TMI}} = 10\,\|\nabla_h \text{TMI}_{1.5}\|$ and $G_{\text{RTP}} = 10\,\|\nabla_h \text{RTP}_{1.5}\|$ (`nT/km`), and 3-D Analytic Signal $|AS_{\text{TMI}}| = \sqrt{G_{\text{TMI}}^2 + (1000\,G_{1.0}(\text{tmi\_vg}))^2}$ (`nT/km`).
   * With $g_T = \operatorname{pct}(G_{\text{TMI}})$, $g_R = \operatorname{pct}(G_{\text{RTP}})$, $a_T = \operatorname{pct}(\log(1 + |AS_{\text{TMI}}|))$:
     $$S_{\text{rem}} = \frac{|g_T - g_R|}{g_T + g_R + 0.05}\,a_T,\qquad \texttt{H74\_remanent\_skew\_crest} = \operatorname{pct}\!\big(\operatorname{ridge\_strength}(S_{\text{rem}}, 1.5)\big).$$
2. **`H74_biharmonic_plate_hinge`:**
   * With $w = \log(1 + \max(\operatorname{nearest\_fill}(\texttt{depth\_to\_base\_surf}), 0))$, compute fourth-order biharmonic defects via cascaded Gaussian-Laplacians at $\sigma \in \{2.0, 4.0\}\text{ px}$: $B_\sigma = |\nabla^2(\nabla^2 w_\sigma)|$ (scaled by $\sigma^4$ for scale-normalized curvature load).
   * Combine multi-scale flexural persistence $B_{24} = \sqrt{\operatorname{pct}(B_2)\,\operatorname{pct}(B_4)}$ with isostatic gravity gradient $g_{\text{iso}} = \operatorname{pct}(\|\nabla_h G_{2.0}(\texttt{iso\_grav\_anom})\|)$:
     $$\texttt{H74\_biharmonic\_plate\_hinge} = \operatorname{pct}\!\big(\operatorname{ridge\_strength}(\sqrt{B_{24}\,g_{\text{iso}}}, 1.5)\big).$$
3. **`H74_simpson_pore_crit`:**
   * From `08_geod_dilaterate` ($\Delta$) and `07_geod_shearrate` ($\dot{\gamma}_{\max} \ge 0$), principal horizontal strain rates are $\dot{\varepsilon}_1 = 0.5\Delta + \dot{\gamma}_{\max}$ and $\dot{\varepsilon}_2 = 0.5\Delta - \dot{\gamma}_{\max}$. Define kinematic transtensional factor $T_{\text{ext}} = 0.5 + 0.5\,\operatorname{clip}\big((\dot{\varepsilon}_1 + \dot{\varepsilon}_2)/(|\dot{\varepsilon}_1| + |\dot{\varepsilon}_2| + 10^{-3}), -1, 1\big) \in [0, 1]$.
   * With $c = \log(1 + \max(\texttt{cond\_surf}, 0))$ and $q = \log(1 + \max(\texttt{ieq\_n100a15}, 0))$, compute local high-pass anomalies $C_{\text{hp}} = \operatorname{pct}(\max(c - G_{15}(c), 0))$ and $Q_{\text{hp}} = \operatorname{pct}(\max(q - G_{25}(q), 0))$:
     $$\texttt{H74\_simpson\_pore\_crit} = \operatorname{pct}\!\big(T_{\text{ext}}\sqrt{C_{\text{hp}}\,(0.25 + 0.75\,Q_{\text{hp}})}\big).$$
4. **`H74_laplace_harmonic_defect`:**
   * For a reflect-padded (`pad=256`, `cell_m=100.0`) mild-smoothed ($\sigma = 1.0\text{ px}$) potential field $F$, compute the exact analytical downward harmonic vertical derivative $V_{\text{FFT}}(F) = \mathcal{F}^{-1}\{+2\pi |\mathbf{k}| \hat{F}(\mathbf{k})\}$ (`cycles/m` wavenumber $|\mathbf{k}|$, units `/m`, verified on synthetic harmonic fields in `tests/test_h74_rmps_bw.py`). Because `09_tmi_vg` has units `nT/m` and `11_iso_grav_anom_vg` has units `mGal/km`, scale $V_{\text{FFT}}(\text{TMI})$ by `1.0` (`nT/m`) and $V_{\text{FFT}}(g_{\text{iso}})$ by `1000.0` (`mGal/km`), and compare absolute magnitudes $|V_{\text{obs}}|$ vs $|V_{\text{FFT}}|$ (sign-convention-invariant across upward/downward z-axis conventions):
     $$D_M = \operatorname{pct}\!\big(\big|\,|G_{1.0}(\texttt{tmi\_vg})| - |V_{\text{FFT}}(\texttt{tmi}_{1.0})|\,\big|\big),\qquad D_G = \operatorname{pct}\!\big(\big|\,|G_{1.0}(\texttt{iso\_grav\_anom\_vg})| - 1000\,|V_{\text{FFT}}(\texttt{iso\_grav\_anom}_{1.0})|\,\big|\big).$$
     $$\texttt{H74\_laplace\_harmonic\_defect} = \operatorname{pct}\!\big(\operatorname{ridge\_strength}(\sqrt{D_M\,D_G}, 1.5)\big).$$
