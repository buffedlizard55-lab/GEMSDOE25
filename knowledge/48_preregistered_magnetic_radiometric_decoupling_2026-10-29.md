## Frozen Experiment 1 (top candidate)

Use the cached `data/work/bands` produced by `scripts/prepare_data.py`, aligned to the hash-pinned sample raster. Never use label-derived features to create the surface. Smooth RTP and TC at sigma 3 px, take Gaussian-gradient magnitudes; robust-normalize using footprint p99 gradients, surface = normalized magnetic gradient / (1 + normalized total-count gradient). Add no learned weights. Compare each standalone gradient with held-out catalogue positives (AUC >0.90 = leakage, stop). Compute surface Spearman against **all** pinned registry rasters before placing dots; abs(rho)>0.90 or undefined rank stops. Place 8,137 dots with 2,537 in r13-holes outside pindrop halo (R2), 5,600 in r13 halo outside pindrop and latticegap halos (R5), sorted by surface in each region; require >3 px from catalogue on every dot (if 2,537 clean R2 cells unavailable, stop). This lane geometry is imposed by registry coverage, not evidence of geological merit. Check every final dot set against **all** pinned registry rasters: >70% within 3 px of any one, or abs(rho)>0.90 stops.

Holdout: shared `gems25.holdout.Holdout`, 20% entire connected segments withheld, quadrants and 15 px collar, draws 140 and 141 x four quadrants, `gems25.metric.dti_binary` alpha .2 beta .8 triangular radius 3 px / 300 m; visible faults masked exactly. Compare same-run CTRL_H35 from pinned prior raster (if unavailable, do not promote); bootstrap the 8 draws for 95% CI. A static label-free surface does not use the held-out fault map; test mask is applied per draw. Decision: only a paired lower 95% CI >0 and lane+format clean could make this candidate eligible for separate selector consideration. No weekly slot or predicted organizer score.
